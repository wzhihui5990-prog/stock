# MU（美光）末日期权 · 开盘双买

参考 `qqq/10-1-qqq末日期权开盘立即买入看涨看跌双买合同`，把同一套玩法搬到 MU 上。

---

## 一、策略

到期日 T，以 **09:30 开盘价** 定价：

```
基准 = round(开盘价 / 5) × 5                  ← MU 行权价 $5 一档
买 Call(基准 + 20) + Put(基准 − 20) 各 1 张     ← 「近」档；点一下可换成 ±30「远」档
买入时刻：09:30 / 09:33 / 09:36 / 09:39        ← 同一套行权价，只是晚几分钟成交
```

出场（报告默认值，界面上可实时改）：**11:00 平仓 · 止盈 +200% · 止损 −70% · 买入时 VIX ≥ 15**

### 交易口径（金额单位）

| 项目 | 值 |
|---|---|
| 合约乘数 | **1 张 = 100 股** |
| 每笔规模 | 1 Call + 1 Put = **2 张 = 200 股**（报告里叫「整组」） |
| 手续费 | **$2 / 张 / 次**；往返 4 次（买 2 卖 2）= **$8** |
| 金额单位 | **美元，已按整组换算、已扣手续费** |

> 脚本内部按「每股价」计算（`COMM = 2×4/100`），写 Excel / 报告时统一 × 100。
> 比率类指标（成本率%、胜率%、振幅%）不受影响。
> 手续费已三重复核：把 `FEE_PER_CONTRACT` 改成 0 重跑，总盈亏相差 **$224 = 28 天 × $8**，逐日差额也都正好是 −$8。

### ⚠ 三个容易搞混的时刻

| 名字 | 含义 | 谁会变 |
|---|---|---|
| **定价时刻** | 行权价按**哪一刻的股价**算 → 决定买哪两份合约 | 换它 = 换一整套行情（`mu_0dte_options_open_a0945_*.xlsx` 是另一套数据） |
| **买入时刻** | 同一套行权价下，**你几点成交** | 只是成交价变了 → 持仓带上了「开盘到那一刻的漂移」，成本价与 P&L 都变 |
| **平仓截止** | 最晚几点平仓（期间可能先触发止盈/止损） | 只影响出场 |

- 报告里两个控件分开：面板里的 **定价基准**（09:30 开盘价 / 09:45 价格），和行权价一览条里的 **买入时刻**。
- **买入时刻必须 ≥ 定价时刻**，否则就是在用未来价格 —— 比如「按 09:45 股价定行权价、09:30 就买」是不允许的，所以 09:45 基准那一块只能 09:45 买。
- 实测：以 09:30 开盘价为基准时，晚到 **09:36 之后收益基本消失**（见第八节）。

## 二、MU 标的的三件事实

| 项目 | 说明 |
|---|---|
| **0DTE 到期日** | **周一 / 周三 / 周五**（含节假日调整）。2~6 月只有周五；**周一/周三的首个到期日是 2026-07-13**。七月四日调整出 **07-02（周四）**；**09-30（周三）无到期**。 |
| **行权价档位** | 固定 **$5 一档** → 基准必须对齐 5 的倍数 |
| **价格量级** | 2026-02 约 $405 → 2026-10 约 $1,036（**注意：这不是真实历史价，是这份数据集里的数值**） |

⚠️ 因为 $5 一档，而 ±20 / ±30 的偏移不是 5 的倍数，所以：
- **±25 这种中间档在 MU 上通常根本不存在**（唯一例外是±20/±30 恰好落在被 5 整除的位置）。看到「缺 ±25」不是数据缺失。
- 以 09:30 开盘价为基准时，**实际买到的偏移不是精确的 ±20**，而是围绕 20/30 摆动 —— 实测 Call 腿平均偏移 **22.45**、Put 腿 **17.55**。

### 明细表 18 列


左轴 = MU 股价，右轴 = 每张期权 / 整组的美元金额（已 ×100）。**蓝点 = 买入、红点 = 卖出**，带十字准线，悬浮看数值与 MU 相对前一日的涨跌幅。

### ⚡ 自动找最优参数

扫描 **32,256 组**（4 买入时刻 × 6 平仓截止 × 4 腿型 × 7 止盈 × 6 止损 × 4 档买入时VIX × 下跌日开关），

## 八、结论与坑

### 默认值是怎么定的（及为什么别当它是最优解）

- **止盈由「最高倍数分布」定**：当组合市值最高倍数 ≥1.10× 占 **89.3%**、≥1.30× **75.0%**、≥1.50× **60.7%**、≥2.00× 35.7%、**≥3.00× 只有 21.4%**。
  所以 +200% 要求 3.0×（命中 21%）而 −40% 止损只要 0.60× 就触发 —— **赔率与胜率错配**。
- **11:00 该平**：组合市值 09:30→11:00 平均 **+21.4%**，11:00→13:00 **−19.9%**，13:00→15:55 中位 **−47.5%**。0DTE 下午是纯时间价值流失。
- ⚠️ **但换样本符号就会翻**：28 天（8~10 月）样本下 `11:00 / +175% / −40%` = $3,134，好于不止盈；把 8 月剔掉只留 9~10 月（15 天）后，**不止盈 $4,038 反而更好**。止损宽度 / VIX 门槛 / 仅下跌日 / 时间止损，同理都会翻。
  **别把默认值当最优解，请看「比值 / 笔数 / 各月是否都为正」。**

### 买入时刻（09:30 ~ 09:39）实测

固定 `11:00 / +175% / −40% / 不过滤`，仅改买入时刻：

| 买入时刻 | 28 天总盈亏 | 胜率 |
|---|---|---|
| 09:30 | $3,134 | 32.1% |
| **09:33** | $2,819 | **39.3%** |
| 09:36 | $192 | 39.3% |
| 09:39 | −$167 | 32.1% |

→ 晚到 **09:36 之后收益基本消失**。开盘头几分钟的漂移正是双买的主要利润来源，再等就被吃掉了。

### VIX：只有「买入那一刻」的这一列有意义

对比 23 天共同样本（都有盘中 VIX），`≥15.5` 时：

| 门槛 | 用 T-1 收盘 VIX | 用买入那一刻 VIX |
|---|---|---|
| ≥15.5 | 9 笔 · $683 · 胜率 22.2% | **11 笔 · $2,603 · 胜率 36.4% · 回撤 $627** |
| ≥16.0 | 胜率 **0%** · −$1,276 | **7 笔 · +$1,005** |

→ 所以报告里**只留一列 `VIX(买入时)`、只留一个 VIX 过滤器**。
但「VIX 越高越好」是**反的**：门槛 ≥15 时 22 笔 $3,419（略优于不过滤），再往上快速变差 —— ≥15.5 → 13 笔 $921、≥16 → 8 笔 $86、≥17 → 1 笔 −$358。

**VIX 口径（无未来函数）**：VIX 5 分钟柱按**起始时刻**命名（`09:25` 柱 = 09:25~09:30，其收盘价就是 09:30:00 的值）。
所以「t 时刻已知的最后一根柱」= `floor(t/5)×5 − 5`：09:30 / 09:33 → `09:25` 柱，09:36 / 09:39 → `09:30` 柱，09:45 → `09:40` 柱。

### 已回测否决的路（方向一致）

## 九、注意事项

- **样本只有 28 天**（2026-08-03 ~ 2026-10-09）。任何单参数（止损宽度 / VIX 方向 / 下跌日 / 时间止损）在「含不含 2026-07」之间**符号都会翻转** —— 这份样本量**不足以定位最优参数**。
- **不要继续叠加过滤条件**：门槛越提笔数越少，最后剩十几笔的「高胜率」基本都是噪声。
- **未计滑点与买卖价差**。0DTE（尤其 ±30 这种偏虚合约）价差可能很宽，实盘会低于回测。
- **止盈/止损按「触发价成交」做了理想化假设**（更保守的写法是按触发那根 bar 的市值成交，本报告用的是后者）。
- VIX 用的是 `^VIX` 全市场恐慌指数，**不是 MU 自己的 IV**。
- `mu_report.html` **零外部依赖**（内联 SVG + 内联 JS），可直接双击打开，无需联网。
- 早期修掉的两个 bug（留档）：
  1. **数据完整性**：某偏移文件只拉了一半时，原先会让当天面板整列全空 → **整天被跳过**，悄悄把 09:45 区块从 39 天砍到 10 天。现已改为**逐个偏移文件比对到期日，缺的腿型整体剔除**并打印警告。
  2. **未来函数**：「仅下跌日买」原先固定用 09:44 的价格判断，入场选 09:30 时等于偷看 14 分钟后的数据。现已与买入时刻对齐：晚于 09:30 用【买入前 1 分钟价 < 当日开盘价】，09:30 买入用【低开】（开盘 < 前收）。
