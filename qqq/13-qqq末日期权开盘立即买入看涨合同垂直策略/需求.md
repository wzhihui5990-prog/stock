# QQQ 末日期权开盘立即买入垂直看涨价差（Bull Call Spread）

## 数据来源
- QQQ 日K 数据：`1-qqq日K`
- 期权日K 数据：`4-qqq末日期权日K-当天开盘上下2和上下3股价的期权合同`
  - 支持 offset 1 / 2 / 3 / 4 / 5，即开盘价 ±1 ~ ±5 的期权日K数据

## 策略说明
垂直看涨价差（Bull Call Spread）= 买入低行权价 Call + 卖出高行权价 Call，同一到期日（0DTE）。

开盘时同时操作：
- **买腿**：以开盘价为基准，买入 `base + buy_offset` 的 Call（低行权价腿）
- **卖腿**：以开盘价为基准，卖出 `base + sell_offset` 的 Call（高行权价腿）
- base = round(QQQ 当日开盘价)
- 约束：`buy_offset < sell_offset`，两者均取整数，且必须满足有对应期权数据
- 例如：buy_offset=1 卖 sell_offset=3，即买 base+1 Call，卖 base+3 Call

## 可配置参数
| 参数 | 说明 |
|---|---|
| buy_offset | 买腿行权价偏移，取值范围 **1~4**（对应 base+1 ~ base+4 的 Call） |
| sell_offset | 卖腿行权价偏移，取值范围 **2~5**（对应 base+2 ~ base+5 的 Call），且必须 > buy_offset |
| take_profit_pct | 止盈触发：价差盈利达到净权利金的 N 倍时平仓（如 1.5 = 盈利 150%） |
| stop_loss_pct | 止损触发：价差亏损达到净权利金的 N% 时平仓（如 0.8 = 亏损 80%） |
| close_time | 强制平仓时间（美东），如 15:45，未触发止盈止损则到时平仓 |
| commission | 手续费，每笔单腿 1.7 元，开仓 2 腿共 3.4 元，平仓同理 |

## 盈亏计算（每天）
- 净权利金 = 买腿开盘价 - 卖腿开盘价
- 最大亏损 = 净权利金 + 手续费
- 最大盈利 = (sell_strike - buy_strike) - 净权利金 - 手续费
- 实际收益 = 平仓时价差 - 净权利金 - 手续费

- 止盈倍数（take_profit_pct，如 1.5 = 盈利 150% 平仓）
- 止损比例（stop_loss_pct，如 0.8 = 亏损 80% 平仓）

- 手续费（$/张）
- "重新计算" 按钮，状态提示文字

## 回测优化脚本要求
- 枚举 buy_offset（1~4）× sell_offset（> buy_offset，2~5）× take_profit_pct × stop_loss_pct × close_time 五轴参数
- take_profit_pct 范围：0.5 ~ 3.0，步长 0.25
- stop_loss_pct 范围：0.3 ~ 1.0，步长 0.1
- close_time 范围：10:00 / 10:30 / 11:00 / 11:30 / 12:00 / 12:30 / 13:00 / 14:00 / 15:00
- 每个参数组合输出：总收益、胜率、最大回撤、触发率、交易天数
- 结果按总收益降序，输出 Top 30 到 CSV
- 同时输出一个 HTML 优化报告，表格高亮 Top 5 组合，并展示参数热力图
